Dev Chat is designed for people on the same home, office, or lab network. Everyone in a chat uses the same relay.

You can host a relay from this VS Code window. It stops when VS Code closes. For a relay that stays available, run the standalone server with Node.js or Docker on a home or office server.

[Host a relay from VS Code](command:devChat.hostRelay)

[Read the standalone relay setup guide](https://github.com/Roarmo/vscode-dev-chat/blob/main/docs/relay-setup.md)

New members must receive a private invitation from the relay administrator. Do not post invitations publicly; they contain a secret join code.
